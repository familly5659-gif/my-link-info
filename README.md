# 모아 · My Link Info

쿠팡파트너스·토스쇼핑 링크와 추천 글을 모으는 개인 상품 보관함입니다. Node.js 24.19.0 이상을 사용합니다.

## GitHub Codespaces에서 실행

Codespaces 아래쪽 터미널에서 다음 명령을 순서대로 실행하세요.

```sh
git pull --ff-only origin main
nvm install 24
nvm use 24
npm ci
HOST=0.0.0.0 npm start
```

서버가 켜지면 **브라우저에서 열기**를 누르세요. 안내가 보이지 않으면 터미널 옆 **포트** 탭에서 **3000**번 포트를 열면 됩니다. 실행 중인 터미널은 그대로 두고, 종료하려면 `Ctrl+C`를 누르세요.

최초 실행 후 왼쪽 탐색기의 `.data/admin-key`를 열어 관리자 키를 확인하고 화면의 **관리자 로그인**에 입력하세요. 관리자 키와 상품 DB는 GitHub에 올라가지 않습니다. 다른 환경에서 사용하던 데이터도 자동으로 옮겨지지 않으므로 첫 실행에서는 예시 카드가 표시됩니다.

## Codex 클라우드 환경에서 실행

```sh
cd /workspace/my-link-info
npm ci --cache /tmp/my-link-npm --ignore-scripts --no-audit --no-fund
npm test
npm start
```

기본 바인딩은 `127.0.0.1`, 포트는 `3000`입니다. `npm run dev`는 파일 변경 시 서버를 재시작합니다. 별도 빌드나 외부 DB가 필요하지 않습니다. cloud task의 기존 체크아웃을 사용하며 별도 worktree를 만들 필요가 없습니다.

## 링크 등록

1. 서버를 실행하면 `.data/admin-key`에 관리자 키가 생성됩니다. 파일 편집기나 비공개 터미널에서 확인해 **관리자 로그인**에 입력하세요. 키를 채팅·저장소·공개 로그에 붙여 넣지 마세요.
2. **링크 추가**에서 쿠팡·토스쇼핑·Threads HTTPS 주소를 입력합니다.
3. **상품 정보 가져오기**를 누르면 공개된 Open Graph 제목·설명·썸네일을 불러옵니다. 사이트 접근 제한 또는 상품 정보 부재 시 직접 입력하세요. Threads 글 안의 상품 링크까지 추출하는 기능이나 AI 요약 생성은 아직 없습니다. 상품을 바로 열려면 실제 제휴 상품 주소를 등록하세요.
4. 제목, 추천 글, HTTPS 이미지 주소, **대분류·소분류**를 확인하고 저장합니다. 예: `주방 → 수세미`, `청소 → 청소용품`. 실제 이미지가 없거나 로딩되지 않으면 기본 썸네일이 표시됩니다.
5. 상품을 클릭하면 **입력한 제휴 URL 그대로** 새 탭에서 엽니다. 수수료 발생·구매 전환을 측정하거나 보장하지 않습니다.

등록한 상품이 없으면 8개의 **예시 아이템**이 표시됩니다. 예시에는 구매 링크가 없으며, 실제 상품을 등록하면 사라집니다. 맨 위 검색창 바로 아래에 썸네일·상품명·한 줄 요약이 있는 가로형 상품 카드가 세로로 나열됩니다. 검색, 수정, 삭제, 페이지 공유와 모바일 화면을 지원하며 관리자 로그인은 페이지 맨 아래에 있습니다.

## 업데이트 후 목록이 비어 있거나 로그인이 안 될 때

업데이트 전에 켜 둔 서버는 새 화면 파일을 읽으면서도 이전 API와 파일 경로를 계속 사용할 수 있습니다. 현재 화면은 분류 정보를 별도 파일 요청 없이 시작하고, 이전 서버가 감지되면 재시작 안내를 표시합니다. `/api/status`에서 실행 중인 버전이 `0.2.1`인지 확인할 수 있습니다. 화면·스크립트·스타일에는 캐시 방지 헤더를 적용합니다.

기존 서버가 어느 터미널에서 실행 중인지 모르면, 새 터미널에서 아래처럼 별도 포트로 최신 서버를 켜세요.

```sh
cd /workspaces/my-link-info
git pull --ff-only origin main
nvm use 24
HOST=0.0.0.0 PORT=3002 npm start
```

그 뒤 Codespaces **포트** 탭에서 **3002**를 추가하고 해당 행의 지구본 아이콘을 누르세요. 기존 3000·3001번 탭 대신 3002번으로 연 페이지를 사용하세요. `.data`를 삭제하거나 관리자 키를 새로 만들 필요는 없습니다.

## 상품 수정·선택 삭제

- 관리자 로그인 후 직접 등록한 상품 아래의 **상품 수정**을 누르면 제목·링크·요약·썸네일·대분류·소분류를 바꿀 수 있습니다. 예시 상품은 둘러보기용이며 수정·삭제 대상이 아닙니다.
- 상품 아래 **선택** 체크박스로 여러 개를 고르거나 **현재 목록 전체 선택**을 누른 뒤 **선택 삭제**를 누르세요. 삭제할 개수를 확인하는 창에서 취소할 수 있으며, 실행한 삭제는 되돌릴 수 없습니다.
- 검색 또는 분류를 바꾸면 선택이 해제됩니다. 전체 선택은 현재 화면의 검색·분류에 해당하는 실제 상품에만 적용됩니다.

## 대분류·소분류 탐색

검색창 아래에서 대분류를 누르면 해당 상품과 소분류가 펼쳐집니다. 소분류를 누르면 그 안의 상품만 표시됩니다. 각 단계의 **전체** 버튼으로 상위 목록으로 돌아갈 수 있으며, 검색은 선택한 분류 안에서 작동합니다.

기본 대분류는 **주방, 청소, 생활·수납, 디지털, 패션·뷰티, 라이프**입니다. 지원 분류는 `public/categories.js`에서 공유합니다. 상품을 추가할 때 현재 보고 있던 분류가 기본으로 선택됩니다.

기존 DB는 서버 시작 시 소분류 필드가 자동으로 추가됩니다. 기존 `살림·주방`은 `주방 → 기타`, 다른 기존 상품은 원래 대분류의 `기타`로 표시됩니다. 제목·링크·추천 글·이미지는 보존되며 **상품 수정**에서 원하는 분류로 옮길 수 있습니다. 기존 `.data` 폴더를 삭제하지 마세요.

## 데이터와 인증

- `.data/links.sqlite`와 SQLite WAL 파일에 상품이 저장됩니다. `.data` 전체를 보존하세요. 백업 시 서버를 중지하거나 SQLite 백업 기능을 사용하세요.
- `DATA_DIR`로 저장 경로를 변경할 수 있습니다. `ADMIN_KEY`로 관리자 키를 지정할 수 있습니다. `HOST`, `PORT`로 바인딩을 변경합니다.
- 관리자 키는 브라우저 `sessionStorage`에 보관하며 로그아웃하면 지웁니다. 공개 API는 조회만 허용하고 변경·메타데이터 수집은 인증이 필요합니다.
- 외부 배포는 별도 작업입니다. HTTPS, 영속 저장소, 안정적인 관리자 키와 백업을 설정한 후 공개하세요. 개발 서버 실행이나 환경 게시가 웹사이트 공개 배포를 의미하지 않습니다.

## 검증

`npm test`는 독립된 임시 DB로 API 인증, 등록·수정·삭제, 제휴 URL 보존, URL 검증, 서버 재시작 후 영속성, 메타데이터 파서를 확인합니다. 현재 실제 브라우저에서 로그인·등록·수정·삭제, 검색, 새로고침 후 데이터 유지와 모바일 레이아웃도 검증했습니다. 화면은 1440px·390px·320px에서 가로 넘침 여부, 대분류·소분류 탐색, 검색·등록·수정, 선택 해제, 전체 선택, 선택 삭제의 취소·실행을 브라우저로 확인했습니다. 자동 테스트 14개에는 기존 DB의 분류 이전 및 재시작, 잘못된 분류 거부, 인증된 선택 삭제와 미선택 상품 보존 검증이 포함됩니다.

최초 Threads 요청은 프록시 HTTP 403으로 거부되었으나, 관련 도메인을 환경 초안에 추가하고 Node 환경 프록시를 활성화한 후 제공된 Threads 글의 제목·본문·썸네일 수집에 성공했습니다. 해당 칼국수 글을 Codex 작업 환경의 로컬 DB에 첫 카드로 저장했으며 요약은 원문을 바탕으로 편집했습니다. 이 로컬 DB는 GitHub에 포함되지 않습니다. 이 카드는 구매 링크가 아닌 Threads 원문으로 연결됩니다. 썸네일 URL 추출은 성공했지만 이미지 CDN 요청은 현재 프록시 HTTP 403으로 차단되어 기본 이미지가 표시됩니다. 환경 설정에서 `scontent-ber1-1.cdninstagram.com` 허용을 적용한 후 재확인해야 합니다. 지원하는 CDN 이미지에는 서버 캐시 경로를 사용하며 `.data/thumbnails`에 보관합니다. 실제 쿠팡·토스 제휴 상품의 자동 수집 성공 여부는 상품 주소로 추가 검증해야 합니다. 사이트 자체 접근 제한은 도메인 허용 후에도 남을 수 있습니다. TLS 검증은 비활성화하지 않습니다.

## 구조

- `server.js`: HTTP API, 관리자 인증, SQLite 저장, 제한된 호스트의 메타데이터 수집
- `metadata.js`: HTML 메타데이터 파서
- `public/`: 반응형 화면과 클라이언트
- `test/`: Node 내장 테스트 러너 기반 테스트
